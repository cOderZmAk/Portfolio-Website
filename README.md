# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This site is a digital showcase of my projects, skills, resume, and professional background. It’s built to reflect my personality, highlight my technical expertise, and serve as a central hub for networking opportunities.

## 📌 Description

This project is a responsive and modern personal portfolio website built using **HTML**, **CSS (Tailwind CSS)**, and **JavaScript**. It provides a smooth user experience, mobile-friendly design, and clearly organized sections to help visitors easily navigate through my work and learn more about me.

### ✨ Features

- 🖥️ Clean and responsive design
- 📄 About Me section
- 🛠️ Projects portfolio with links and descriptions
- 📬 Contact form or contact information
- 📜 Resume/CV download link
- 🔗 Social media and GitHub integration

## 🛠️ Built With

- **HTML5** – Semantic page structure  
- **Tailwind CSS** – Utility-first CSS framework for fast UI development  
- **JavaScript** – Simple interactivity (animations, toggles, etc.)
